Börja med lokalen

Tre vyer gör det lättare att förstå omfattningen

Vid en lagerutrensning är frågan inte främst hur många identiska artiklar som finns, utan vad som står i vägen och vad som kan få en annan användning.

01Hela lokalen

Översiktsbild som visar gångar, hyllor och hur mycket plats sakerna tar.

02Större objekt

Närbilder på maskiner, redskap och utrustning som ni vill få bort.

03Blandat innehåll

Lådor, hyllor, lösa delar – beskriv ungefär vad som finns i dem.

Bilderna kan tas med mobil. Om tre foton inte räcker för att visa en större lokal kan ni beskriva resten i text, så frågar vi efter mer vid behov.

Vad kan lämna lokalen?

Vi skiljer på intressanta objekt och sådant som kräver en annan lösning

En lokal kan rymma mycket som inte hör ihop. Därför är det viktigt att skilja sådant vi kan överväga att köpa från sådant som inte automatiskt ingår.

✓

Det vi gärna tittar närmare på

  • Maskiner, redskap och utrustning som blivit stående.
  • Reservdelar, komponenter och verktyg.
  • Avgränsade maskin- eller materialpartier med möjligt återbruksvärde.

Även trasiga eller ofullständiga maskiner kan vara intressanta.

?

Det som behöver avgränsas

  • Vanligt skräp och sådant som saknar koppling till vår verksamhet.
  • Städning, sortering och avfallshantering av hela lokalen.
  • Tung lastning, svår åtkomst eller objekt som kräver särskild hantering.

Vi gör ingen generell utfästelse om att tömma ett helt lager eller hämta allt kostnadsfritt.

Har ni redan ett färdigt varuparti att sälja?

Då är överskottslager mer träffande. Den sidan gäller överblivna artiklar och reservdelar som kan säljas utan att hela lokalen ska rensas.

Praktiskt genomförande

Från full lokal till en tydlig överenskommelse

Först när vi vet ungefär vilka objekt det gäller kan vi avgöra om ett köp och en eventuell hämtning är möjlig.

1

Visa utrymmet

Skicka översiktsbilder, ort och varför ni behöver frigöra plats. Nämn gärna om lokalen ska vara tom ett visst datum.

2

Peka ut viktiga saker

Identifiera större maskiner och partier som kan vara aktuella. Allt måste inte namnges.

3

Avgränsa vad som ingår

Vi återkommer om vilka objekt som är intressanta och diskuterar pris, åtkomst och eventuell transport.

4

Besluta tillsammans

Eventuell affär och hämtning genomförs först efter överenskommelse om omfattningen.

Vilken lösning passar?
