# Bilder till Hjo-sidorna

Denna mapp innehåller publicerbara bilder från användarens egna fotografier. **Ladda upp WebP-filerna i denna mapp** innan PR:n slås samman. HTML-sidorna pekar på `/bilder/hjo/filnamn.webp`, och bilderna visas inte förrän filerna finns.

Urval: 14 WebP-filer i paketet `hjo-bildurval-webb.zip` (varav 13 används i nuvarande fotodesign). Bilderna är optimerade och EXIF är borttaget.

- salja-maskiner-traktor-hamtning.webp
- salja-maskiner-ford-traktor.webp
- salja-maskiner-traktor-lastare.webp
- akgrasklippare-parti-slap.webp
- akgrasklippare-gard.webp
- akgrasklippare-orange-husqvarna.webp (reserv)
- grasklippare-slap-blandat.webp
- grasklippare-och-verkstadsutrustning.webp
- skrot-metallror.webp
- skrot-redskap.webp
- parti-blandade-objekt.webp
- verkstad-motorutrustning.webp
- aterbruk-aldre-husqvarna.webp
- aterbruk-aldre-motorcykel.webp

## Publicering

1. Byt till grenen `feature/hjo-fotografier-layout-20261021` på GitHub.
2. Öppna denna mapp (`bilder/hjo/`) och välj **Add file → Upload files**.
3. Packa först upp ZIP-filen lokalt, dra in **alla 14 .webp-filerna**, och spara med **Commit changes** i samma gren.
4. Kontrollera att bildvägarna matchar exakt (inklusive gemener).
5. Granska PR och slå endast samman den efter att alla bildfiler finns och bilden/texterna godkänts.

## Redaktionellt

Beskriv inte bilder som hämtade i Hjo utan verifierad ort. Blandat parti på dödsbo-sidan är ett exempel, **inte** en verifierad dödsbohämtning. Kontrollera synliga registreringsnummer och andra identifierande detaljer innan publicering. Undvik att tolka skick som verifierat bara från fotot.
